# 日报管理系统

一个无需构建工具、打开浏览器即可使用的轻量日报管理页面。界面为中文，适配桌面和移动设备。

## 功能

- 新建、编辑和删除日报
- 记录日报日期、标题、今日工作内容、明日计划及状态（已提交/草稿）
- 按关键词、状态和日期筛选
- 显示日报总数、本周已提交数和最近提交日期
- 导出 JSON 备份
- 使用浏览器 `localStorage` 在本机保存数据

## 使用

直接在浏览器中打开 `index.html` 即可。也可以通过任意静态文件服务器发布此页面。

> 当前版本是纯前端单机版，数据仅保存在当前浏览器中，不会自动同步到其他设备或用户。清除浏览器站点数据会删除日报；重要数据请定期使用“导出数据”备份。

## GitHub Pages

仓库包含 `index.html`，可在仓库 **Settings → Pages** 中选择从 `main` 分支根目录部署。部署完成后即可通过 Pages 地址访问。
